CGSpace publication finder

Look up research outputs on CGSpace by a colleague's email, author name or ORCID iD. CGSpace does not store emails, so the finder works out the author name from the email (e.g. e.kihoro → “Kihoro, E”) and shows you the matching names on CGSpace to confirm.

People list

Name as it appears on CGSpace (surname first works best, e.g. “Krupnik, T”). Saved only in this browser.

    Import people from CSV

    Columns: name, email, orcid, and optionally “name spellings” (separate several with semicolons). Put names containing commas in quotes, e.g. "Krupnik, T",t.krupnik@cgiar.org,0000-0001-6973-0106

    Connection settings

    If searches fail with a connection error, deploy the proxy file that comes with this dashboard and paste its address here, ending in /server/api.

    Match this person by

    Separate alternatives with commas. Within one alternative, all words must appear — “rice seed, maize seed” finds outputs about rice seed or maize seed.

    Search in

    Finds outputs on CGSpace about this area, then ranks their authors by how many of those outputs they wrote.

    Find someone's outputs

    1. Add colleagues to the people list, or import them from a CSV.
    2. Type an email above and pick it from the suggestions.
    3. Narrow by year, then download the results as a spreadsheet.

    You can also search any author name or ORCID iD without adding them first.
